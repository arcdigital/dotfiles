# Third-party assets

- `find-skills`: https://github.com/vercel-labs/skills/tree/main/skills/find-skills (MIT; license in `vercel-skills.txt`). The repository contains the locally installed skill's text.
- Catppuccin k9s Mocha theme: https://github.com/catppuccin/k9s/blob/main/dist/catppuccin-mocha.yaml (MIT; license in `catppuccin-k9s.txt`).
- Catppuccin zsh-syntax-highlighting Mocha theme: https://github.com/catppuccin/zsh-syntax-highlighting/blob/main/themes/catppuccin_mocha-zsh-syntax-highlighting.zsh (MIT; license in `catppuccin-zsh-syntax-highlighting.txt`).
- Catppuccin bottom Mocha theme: https://github.com/catppuccin/bottom/blob/main/themes/mocha.toml (MIT; license in `catppuccin-bottom.txt`).
- Catppuccin bat Mocha theme: https://github.com/catppuccin/bat/tree/6810349b28055dce54076712fc05fc68da4b8ec0 (MIT; adjacent license).
- Nerd Fonts: https://github.com/ryanoasis/nerd-fonts (public wrapper uses the official image; no glyph assets are vendored).
- zsh-autosuggestions and zsh-syntax-highlighting: upstream Git checkouts from the zsh-users repositories under `~/.local/share/dotfiles/plugins/`; each checkout contains its license and commit history.

- Atuin Catppuccin Mocha Mauve theme: https://github.com/catppuccin/atuin at `68aa64b77573c235044b614e752a781701af4eec`; MIT license in `catppuccin-atuin.txt`.
